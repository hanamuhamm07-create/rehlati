رحلتي الدراسية — التحديث

المحتويات:
- index.html: النسخة المحدّثة من التطبيق مع خطة الالتزام والمواد والأساتذة.
- sw.js: عامل الخدمة مع رقم تخزين جديد لتحديث النسخة دون بقاء الصفحة القديمة في ذاكرة التخزين.

التثبيت على GitHub Pages:
1) احتفظي بنسخة احتياطية من بيانات التطبيق من صفحة النسخ الاحتياطي قبل استبدال الملفات.
2) افتحي مستودع GitHub الخاص بالموقع.
3) استبدلي index.html بالملف الموجود هنا، واستبدلي sw.js أيضًا.
4) احفظي التغييرات وانتظري نشر GitHub Pages.
5) افتحي رابط الموقع، وإذا ظهرت النسخة القديمة أغلقي التبويب وافتحيه مجددًا أو امسحي بيانات الموقع المؤقتة بعد التأكد من وجود نسخة احتياطية.

مهم: هذا تحديث لملفات التطبيق فقط. لم يتم نشره على GitHub نيابةً عنك، ولم يتم اختبار الموقع المنشور أو مزامنة بيانات الأجهزة.
